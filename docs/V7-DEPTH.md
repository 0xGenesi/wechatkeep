## 4. 需求重写（对原句的第四代转译）

- **R19（完备性封口）**：状态机主张的定义域从「≤4 长序列」升格为「全部
  长度」——以有限的单群饱和计算替代任何深度数字。验收：L15 五判据全绿。✅
- **R20（崩溃模型升格）**：崩溃安全主张同时覆盖合作式（throw，L10 已证）与
  非合作式（SIGKILL）两个故障模型。验收：L16 矩阵 + 抖动臂全绿。✅
- **R21（独立性升格）**：引擎写入语义有第二独立实现背书；随机差分零分歧。
  验收：L17 60 试验 × 多种子逐字节恒等零分歧（SOP 可加大）。✅
- **R22（不变量机检化）**：目录的结构完整性不再依赖人工目检；家族断言常态
  机检。验收：L18 全 catalog 审计绿 + 白名单有出处。✅
- **R23（证据可复算）**：台账从「记录历史」升格为「可重推导」；第三方重跑
  复算门可复验全部判定。验收：`make evidence-recheck` 绿。✅
- **R24（反目标与边界）**：产品行为零变更（CLI 表面、字节产出不变）；
  124-②applySwaps 启动清扫为唯一例外（既登记强化，附回归测试）。未完成项
  的处理原则 =「机器可做项全做；用户窗口项 turnkey 化 + 精确登记」，
  虚报完成是最大的恶。✅

### 设计修正（本轮揭出的不合理处）

1. **「穷举到深度 4」仍有无限尾巴**——「浅层蕴含」是论证不是证明；单群
   饱和把尾巴变成数学事实（R19）。
2. **「throw 注入 = 崩溃」的模型混同**——优雅错误与断电是两个世界；
   L10 的五不变量在 SIGKILL 模型下必须重证（R20）。
3. **「Python 工具若干 = 独立性」的粒度错觉**——单性质复算不等于引擎
   语义孪生；系统性差分才是独立性（R21）。
4. **「家族断言写在 ROADMAP 里」= 无守卫**——散文不变量在数据被机械
   改动（auto-PR）时静默失守；机检化（R22）。
5. **「台账存在 = 证据在」的时间错觉**——历史记录可能漂移失真；
   复算门让证据活在当下（R23）。
6. **「完成所有未完成的项」的全称冲动**——5 个在册项需要真人对真微信
   发真撤回（行为五格/M4 认证值/副本 E2E），机器不可替代；诚实转译为
   「机器可做项全做 + 用户窗口项 turnkey」（R24）。

## 6. 验收与诚实边界

- ✅ 本轮达成：R19-R24（判定见 §3；台账 var/logs/）。
- ⏳ **未证明面（显式登记）**：
  - L15 的「类内一致」是**采样自证**而非穷举——残差假设（同变换类的
    不同词在引擎上产生相同字节）由每类 ≥1 个非最短词直接复核，但不构成
    全称证明；全称性来自「引擎为确定性状态机 + 折叠语义只依赖抽象态」
    这一模型假设，假设本身由 L17 差分孪生交叉背书。
  - L16 抖动臂覆盖**墙钟粒度**——SIGKILL 无法落在指令边界精确点；
    位点粒度的非合作覆盖由同缝自毙臂承担（kill-at(k)），两臂互补。
  - L17 孪生与引擎**共享 spec**（config.json 语义）——发现的是实现分歧，
    不是 spec 分歧；spec 本身的正确性归 L1 地面真值 + 真机行为验收。
  - L18 家族签名是**人工归纳的签名**——签名本身的完备性不主张；
    它守卫的是「已知家族结构不被无声破坏」。
  - L19 复算的是**判定行**，不是全文件字节恒等——时间戳/耗时等环境
    噪声白名单化；判定语义（PASS/FAIL + 计数）必须恒等。
  - 用户窗口项（3.x 行为五格、M4 认证值 r8pub/r9pub、clsvc 副本 E2E）
    维持在册——本仓的诚实传统。
